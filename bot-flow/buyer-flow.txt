2. BROKER DISPATCH LOGIC & REGEX TRIGGER (customFlow.ts)
================================================================================
- Triggers when user sends text matching: /BROKER:\s*([A-Za-z0-9_-]+)/i
  Example: "BROKER: INDORE1001" or "BROKER: REF99"

- EXECUTION PIPELINE:
  1. Extract Broker Code from payload.
  2. Query DB / API to validate partner referral / agency code.
  3. IF VALID:
     - Update user session role to `ROLE_BROKER`.
     - Link WhatsApp phone number to Broker Profile.
     - Send Welcome / Verification Success card.
     - Present Quick Action Menu: [List Property] | [View Leads] | [My Inventory]
  4. IF INVALID:
     - Prompt error message: "Invalid Broker Code. Please check and try again or contact support."

================================================================================
3. PROPERTY LISTING STATE MACHINE (defaultFlow/list/index.ts)
================================================================================

STEP 1: Listing Intent (step1ListingType.ts)
---------------------------------------------
- Prompt: "What would you like to list today?"
- Component: 2 Quick Reply Buttons
  * [list_intent_sell] -> "🏷️ For Sale"
  * [list_intent_rent] -> "🔑 For Rent"

STEP 2: Property Category (step2Category.ts)
---------------------------------------------
- Prompt: "Select property category:"
- Component: 2 Quick Reply Buttons
  * [list_cat_res]  -> "🏠 Residential"
  * [list_cat_comm] -> "🏢 Commercial"

STEP 3: Sub-Category & Specifications (step3Details.ts)
-------------------------------------------------------
- Component: Interactive List followed by dynamic quick replies / text input.
  * Residential: Flat / House / Plot / Farmhouse
    - Ask BHK / Plot Sq Ft / Furnishing status
  * Commercial: Office / Shop / Land / Warehouse
    - Ask Carpet area (Sq Ft)

STEP 4: Location Details (step4Location.ts)
-------------------------------------------
- Component: Multi-step location capture
  1. Interactive List -> Select City (INDORE, BHOPAL, MUMBAI, PUNE, etc.)
  2. Free Text Request -> Enter Locality / Colony / Landmark name.

STEP 5: Pricing (step5Price.ts)
-------------------------------
- Component: Free-Text Request
  * For Sale: "Enter expected total selling price (e.g., 45 Lakhs or 1.2 Crore):"
  * For Rent: "Enter monthly expected rent (e.g., 15000):"

STEP 6: Listing Summary & Confirmation (step6Confirmation.ts)
--------------------------------------------------------------
- Generates structured Markdown receipt:
  - Listing Code / ID
  - Property Type & Specs
  - Location Details
  - Asking Price / Rent
- Component: 2 Quick Reply Buttons
  * [confirm_publish] -> "✅ Publish Listing"
  * [confirm_cancel]  -> "❌ Cancel / Edit"
